# Framboisia — site vitrine

Site statique (HTML, CSS, JS), sans dépendances ni étape de build.

## Structure
- index.html, produits.html, histoire.html, contact.html
- assets/css/style.css, assets/js/main.js
- assets/img/, assets/video/

## Lancer en local
Ouvrir index.html dans un navigateur, ou : `npx serve .`

## Déploiement
Netlify : relier le dépôt GitHub, dossier de publication `.`, aucune commande de build.

## Modifier
- Numéro WhatsApp : rechercher `221784169909` (HTML + main.js)
- Prix : `PRICE` dans main.js et les montants dans produits.html
